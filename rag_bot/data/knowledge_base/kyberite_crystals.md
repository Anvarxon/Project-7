# Kyberite Crystals

Kyberite Crystals - редкие резонаторы, усиливающие Synth Flux в приборах и оружии. Из них собирают сердечник prism blade, фазовые фильтры HyperRelay Grid и часть навигации Crosswind Spear. Чистый кристалл отвечает ровным синим светом, загрязненный - дробным зеленым мерцанием. Aurelian Order запрещает добычу Kyberite Crystals рядом с населенными куполами Elyra.
