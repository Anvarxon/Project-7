# HyperRelay Grid

HyperRelay Grid - коммуникационная сеть, передающая сообщения между секторами быстрее обычного foldstream-курьера. Узлы сети питаются импульсами Void Core, а Kyberite Crystals стабилизируют фазу сигнала. Если кристаллы загрязнены, сообщение распадается на зеркальные пакеты и Sentinel Droids фиксируют ложную тревогу. Поэтому регламент Free Systems League требует проверять источник энергии и журнал фаз перед каждым запуском.
