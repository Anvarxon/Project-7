# Aurelian Order

Aurelian Order - орден навигаторов и хранителей Synth Flux. Его участники не управляют политикой напрямую, а проверяют, чтобы технологии вроде Nova Gate и HyperRelay Grid не разрушали баланс миров. В поздний период орден был почти уничтожен Caldor Protocol. Выжившие мастера Mira Kennon и Yodo Varn учили учеников короткими проверочными ритуалами: сначала наблюдать, затем сверять источник, затем действовать.
