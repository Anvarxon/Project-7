# Orbital Siege of Void Core

Orbital Siege of Void Core - операция Free Systems League против боевой станции Meridian Directorate. Arin Solvar вел Crosswind Spear через узкий foldstream, Lyra Ordan координировала переговоры с Elyra, а Kael Rendar эвакуировал техников на Aurora Kestrel. Победа стала возможной, когда Starlit Archive подтвердил слабый теплоотвод станции. После осады Pact of Elyra получил обязательный аудит военных энергосистем.
