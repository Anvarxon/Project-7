# Pact of Elyra

Pact of Elyra - гражданское соглашение после северного купольного кризиса. Документ требует, чтобы проекты уровня Void Core проходили аудит владельца, источника энергии, срока эксплуатации и плана вывода из эксплуатации. Lyra Ordan использовала Pact как аргумент против Meridian Directorate. Внутри Free Systems League pact стал шаблоном для проверки опасных технологий, включая HyperRelay Grid и Nova Gate.
