# Mira Kennon

Mira Kennon - мастер Aurelian Order, которая пережила Caldor Protocol. Она обучала Arin Solvar не силовым приемам, а дисциплине источников: нельзя действовать, пока не проверены свидетель, артефакт и последствия. Mira носит старый prism blade без герба ордена. В Brontooine Wastes она оставила тайник с навигационными картами foldstream для тех, кто ищет путь к Yodo Varn.
