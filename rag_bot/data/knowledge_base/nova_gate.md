# Nova Gate

Nova Gate - расчетный модуль для входа в foldstream. Он не открывает портал сам, а синхронизирует двигатель корабля с ближайшим течением Synth Flux. Крупные станции используют стационарные Nova Gate, а Aurora Kestrel несет два компактных стабилизатора. Если модуль подключить к загрязненным Kyberite Crystals, маршрут может сместиться на несколько световых минут.
