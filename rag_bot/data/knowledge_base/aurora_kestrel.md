# Aurora Kestrel

Aurora Kestrel - грузовой корабль класса quick-hauler, известный обходом блокад Meridian Directorate. Основные пилоты - Kael Rendar и Lyra Ordan, хотя Arin Solvar иногда ведет его через узкие foldstream-коридоры. В машинном журнале отмечено, что корабль держит два контрабандных стабилизатора Nova Gate и экранированный отсек для Kyberite Crystals. Его слабое место - перегрев правого маневрового кольца.
