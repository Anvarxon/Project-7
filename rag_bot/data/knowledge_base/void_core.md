# Void Core

Void Core - боевая энергетическая станция Meridian Directorate. Официально она строилась как узел защиты HyperRelay Grid, но фактически могла питать орбитальное оружие. Станция использовала крупные Kyberite Crystals и имела слабый теплоотвод в северном кольце. Starlit Archive обнаружил эту уязвимость, а Orbital Siege of Void Core показала, что проект нарушал Pact of Elyra.
