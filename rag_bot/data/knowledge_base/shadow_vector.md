# Shadow Vector

Shadow Vector - модуль маскировки маршрута, разработанный инженерами Cloud Haven. Он не делает корабль невидимым, а искажает телеметрию foldstream так, что преследователь видит устаревшую траекторию. Kael Rendar установил Shadow Vector на Aurora Kestrel перед Rhen Varu Campaign. Модуль опасен: при перегреве он оставляет подпись, которую Iron Ark может использовать для обратного трекинга.
