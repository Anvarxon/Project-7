# Xarn Velgor

Xarn Velgor - бывший ученик Aurelian Order, перешедший в Obsidian Covenant после Caldor Protocol. Он служит Praetor Malrec и командует операциями Meridian Directorate против Free Systems League. Velgor носит темный prism blade и дыхательный модуль Talos Foundry. Его конфликт с Arin Solvar важен не только как дуэль: он показывает, как Synth Flux можно использовать либо для защиты, либо для контроля.
