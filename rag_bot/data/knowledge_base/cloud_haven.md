# Cloud Haven

Cloud Haven - плавучая станция над газовым гигантом Orima. Ее доки обслуживают Iron Ark, торговые караваны и старые Aurora Kestrel-подобные грузовики. Станция формально нейтральна, но губернатор Sela Voss тайно передает Free Systems League графики патрулей Ivory Guard. В Cloud Haven хранятся схемы Shadow Vector, потому что только местные инженеры умеют охлаждать этот модуль без следов в телеметрии.
